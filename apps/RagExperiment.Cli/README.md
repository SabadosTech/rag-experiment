# Propósito
Aplicación experimental interactiva y raíz de composición.

# Responsabilidades
Alojamiento, configuración, inyección de dependencias, selección de proveedores, registro de eventos y ciclo de vida.

# Qué corresponde a este proyecto
Infraestructura de inicio y futuros comandos para experimentos.

# Qué NO corresponde a este proyecto
Implementaciones de algoritmos de recuperación o un contenedor administrado por una biblioteca.

# Dependencias del proyecto
RagExperiment.Core, RagExperiment.Retrieval, RagExperiment.Concepts, RagExperiment.Generation, RagExperiment.Evaluation
