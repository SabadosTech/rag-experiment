# Propósito
Experimentos independientes de recuperación de información.

# Responsabilidades
Recuperación vectorial, con BM25, por conceptos e híbrida; transformación de consultas, fusión y reordenamiento de resultados.

# Qué corresponde a este proyecto
Estrategias de recuperación y ordenamiento que puedan probarse de forma independiente.

# Qué NO corresponde a este proyecto
Generación de respuestas y composición de las aplicaciones.
