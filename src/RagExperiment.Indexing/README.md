# Propósito
Indexación y almacenamiento.

# Responsabilidades
Índices vectoriales, léxicos, de conceptos y de metadatos.

# Qué corresponde a este proyecto
Adaptadores intercambiables de índices, incluidas futuras implementaciones con Qdrant y Lucene.NET.
Lucene.Net 4.8.0-beta00018 está referenciado para los futuros índices léxicos y experimentos con BM25. Su versión se administra centralmente; todavía no se crean índices ni se implementa la recuperación.

# Qué NO corresponde a este proyecto
Coordinación de la recuperación y selección de proveedores de modelos.

# Dependencias del proyecto
RagExperiment.Core
