# Propósito
Generación de respuestas después de la recuperación.

# Responsabilidades
Construcción de instrucciones para el modelo y acceso a modelos conversacionales mediante IChatClient.

# Qué corresponde a este proyecto
Generación de respuestas a partir del contexto recuperado proporcionado y las abstracciones de Microsoft.Extensions.AI.

# Qué NO corresponde a este proyecto
Recuperación y acoplamiento a proveedores específicos.

# Dependencias del proyecto
RagExperiment.Core
