# Propósito
Evaluación de los resultados experimentales.

# Responsabilidades
Evaluación independiente de la recuperación y, más adelante, de las respuestas.

# Qué corresponde a este proyecto
Métricas de recuperación, conjuntos de datos de evaluación y comparaciones entre experimentos cuando se implementen.

# Qué NO corresponde a este proyecto
Ejecución de la ingesta y acoplamiento de la evaluación de recuperación a un modelo de lenguaje.

# Dependencias del proyecto
RagExperiment.Core, RagExperiment.Retrieval
